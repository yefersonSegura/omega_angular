# About

**Omega** (Flutter and Angular stacks) is created and maintained by **[Yeferson Segura](https://yefersonsegura.com/)** — software developer focused on **mobile**, **web**, and **high-impact product engineering**.

Yeferson’s [portfolio](https://yefersonsegura.com/) showcases projects and experience across stacks. The Omega architecture packages — **[omega_architecture](https://pub.dev/packages/omega_architecture)** on pub.dev for Dart/Flutter and **omega-angular** for Angular — share one **intent / flow / agent** mental model so teams can align documentation and patterns when shipping on more than one platform.

If you use Omega in production or want to collaborate, opening a discussion or issue on the **[GitHub repository](https://github.com/yefersonSegura/omega_angular)** is the best place to reach the project directly.

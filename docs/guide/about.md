# About

**omega-angular** and the Omega architecture direction for the web are created and maintained by **[Yeferson Segura](https://yefersonsegura.com/)** — software developer focused on **mobile**, **web**, and **high-impact product engineering**.

Yeferson’s [portfolio](https://yefersonsegura.com/) showcases projects and experience across stacks. **[omega-angular](https://www.npmjs.com/package/omega-angular)** on npm is the packaged library and tooling described on this site; the **[GitHub repository](https://github.com/yefersonSegura/omega_angular)** hosts the source, example app, and issue tracker.

If you use Omega in production or want to collaborate, opening a discussion or issue on the **[GitHub repository](https://github.com/yefersonSegura/omega_angular)** is the best place to reach the project directly.
